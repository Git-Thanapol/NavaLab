## News

- Removed all mockup news articles (3 placeholder-generator ones + a CNN/propeller-diagnosis one
  that was created earlier in this session specifically as a demo — user asked to delete "all
  mockup articles", which included it).
- Added a real article: **"NavaLab Wins Mirai Catalyst Hackathon Challenge 2026 with ScanTu"** —
  covers the NRCT/TSAJ hackathon event and highlights team Krapao Desu's win (Thanapol + Athiphach
  on the team). Technical details of ScanTu (container inspection: gate OCR + 360° interior scan
  robot + 3-tier AI pipeline — YOLO detect / Mask R-CNN measure / VLM reason) were extracted from
  the pitch deck PDF via `pdftotext` (Thai font subsetting made `Read`'s built-in PDF renderer
  unusable — no `poppler`/`pdftoppm` on this machine, but `pdftotext` was available).
- Extended the news schema/CMS/view to support things it couldn't do before:
  - **Code/formula blocks**: `NewsDetailView.astro` now parses fenced ` ``` ` blocks *before*
    splitting the body into paragraphs. First attempt split on blank lines first, which broke
    apart any code block that itself contained a blank line (e.g. Python with a blank line between
    imports and a function def) — fixed by extracting fenced blocks up front, then splitting only
    the remaining text.
  - **Image galleries**: added a `gallery: { image, caption }[]` field to the `news` schema
    (mirrored in `public/admin/config.yml` — schema and CMS config are independent definitions,
    nothing catches drift automatically). Used for the Mirai Catalyst article's two pitch-deck
    diagram images. Also caught and fixed a mistake where the two images had been copied in under
    swapped filenames.
  - Gallery images were initially rendered with a forced `height` that didn't match the source
    aspect ratio (1920×1080 slides forced into a 1200×800 box), cropping the edges. Fixed by
    dropping the forced height so Astro derives it from the image's real aspect ratio.

- Full homepage redesign from a reference mockup image:
  - **Hero**: full-bleed background photo (container ship at sea) with a left-to-right fade so the
    heading text stays legible, plus a wave-shaped SVG cutout along the bottom edge. Quote card
    (using the existing `visionStatement` field) restyled with a large quote-mark glyph and an
    accent-colored flag strip. CTA button restyled to a solid navy pill with an arrow icon.
  - **Expertise grid**: numbered top-border cards → centered icon-badge cards (circle icon +
    title + description + thin accent underline).
  - Icons are from **Bootstrap Icons**, installed as an npm package (`bootstrap-icons`) and
    imported per-icon as raw SVG (`?raw` imports) — not a CDN/icon-font, consistent with the rest
    of the project being fully self-hosted (fonts are npm packages too, not Google Fonts CDN).

  top of the circle (`object-top`), which looked off-center on transparent-background photos with
  inconsistent padding — changed to `object-center`. Replaced the hexagon-cluster SVG backdrop
  with two real backdrop images (wave/current line-art patterns) that alternate by the member's
  `order` field (even → backdrop 1, odd → backdrop 2). Reused the same component on the homepage
  team grid (`MemberCard.astro`), which previously used a plain `object-cover` crop with no
  backdrop handling at all.
- Bumped body-copy text size: `--text-base` 16px → 18px, `--text-lg` 18px → 20px, in the Tailwind
  `@theme` block in `global.css`. Deliberately did *not* touch `--text-sm`, since nav links,
