# คู่มือแก้เนื้อหาเว็บ NavaLab (สำหรับ admin)

เว็บไซต์นี้แก้เนื้อหาได้ทั้งหมดผ่านหน้า `/admin` ไม่ต้องแตะโค้ด ทุกครั้งที่กด "Save" ระบบจะ commit เข้า GitHub และเว็บจะอัปเดตให้อัตโนมัติภายในประมาณ 1 นาที

## เข้าใช้งาน

1. ไปที่ `https://<โดเมนเว็บ>/admin/`
2. กด **Sign In with GitHub** แล้ว login ด้วยบัญชี GitHub ที่มีสิทธิ์เข้าถึง repo

## โครงสร้างเมนู

- **สมาชิก / Members** — โปรไฟล์สมาชิกทั้ง 10 คน (หรือมากกว่า)
- **โปรเจกต์ / Projects** — งานวิจัย/โปรเจกต์ของกลุ่ม
- **ข่าวและกิจกรรม / News** — ข่าวสารต่างๆ
- **ตั้งค่าเว็บไซต์ / Site Settings** — ข้อความหน้าแรก (วิสัยทัศน์, ความเชี่ยวชาญ, อีเมลติดต่อ)

## เพิ่มสมาชิกใหม่

1. เข้าเมนู **สมาชิก / Members** → กด **New**
2. กรอกทุกช่องเป็น **ทั้งสองภาษา** (ไทย/English) — เว็บจะแสดงตามภาษาที่ผู้ชมเลือก
3. **ลำดับการแสดงผล (Order)** กำหนดว่าใครขึ้นก่อนในหน้ารายชื่อทีม
4. **รูปโปรไฟล์** แนะนำรูปแนวตั้ง พื้นหลังสว่างสม่ำเสมอ ระบบจะปรับขนาดให้อัตโนมัติ
5. ช่องที่มีปุ่ม **+** (เช่น ความเชี่ยวชาญ, ประวัติการศึกษา, งานวิจัย, ผลงานตีพิมพ์) เพิ่มได้กี่รายการก็ได้ ไม่กรอกก็ได้ถ้ายังไม่มีข้อมูล — เว็บจะซ่อน section นั้นให้อัตโนมัติถ้าว่าง
6. **โปรเจกต์ที่เกี่ยวข้อง** เลือกจากรายการโปรเจกต์ที่มีอยู่แล้ว (ต้องสร้างโปรเจกต์นั้นไว้ก่อน)
7. กด **Publish** ด้านบนขวาเมื่อเสร็จ

## แก้ข้อความหน้าแรก

เข้าเมนู **ตั้งค่าเว็บไซต์ / Site Settings** → **หน้าแรก / Home page** แก้หัวข้อ, วิสัยทัศน์, และรายการความเชี่ยวชาญของกลุ่มได้จากที่เดียว

## ข้อควรระวัง

- ทุกฟิลด์ที่มีช่อง "ไทย" กับ "English" คู่กัน **ต้องกรอกทั้งสองช่อง** ไม่งั้นฝั่งที่ไม่ได้กรอกจะว่างเปล่าเวลาสลับภาษา
- การลบ (Delete) ทำถาวร แต่ทุกการเปลี่ยนแปลงถูกบันทึกเป็นประวัติใน GitHub เสมอ — ถ้าลบผิดสามารถขอให้ผู้ดูแลระบบ (ที่เข้าถึง GitHub ได้) กู้คืนจากประวัติ commit ได้
- ถ้าบันทึกแล้วเว็บยังไม่เปลี่ยน รอสัก 1-2 นาที (ระบบกำลัง build) ถ้าเกิน 5 นาทียังไม่เปลี่ยน ให้แจ้งผู้ดูแลระบบตรวจสอบ `docker compose logs webhook builder`

## แก้ไฟล์แบบ local (ไม่ต้อง deploy จริง)

สำหรับผู้ดูแลระบบที่อยากทดสอบ CMS บนเครื่องตัวเองก่อน:

```bash
npx decap-server        # เปิดค้างไว้อีกหน้าต่างหนึ่ง
npm run dev              # เปิดเว็บ dev server
```

แล้วเข้า `http://localhost:4321/admin/index.html` เลือก **Work with Local Repository** แล้วชี้ไปที่โฟลเดอร์โปรเจกต์ — การแก้ไขจะเขียนลงไฟล์ในเครื่องโดยตรง ไม่ผ่าน GitHub
